Aula 01 - Morfologia

Artigo, Substantivo e Adjetivo

A Morfologia é o estudo voltado para a estrutura, a formação e a classificação das palavras isoladas do seu contexto e de suas funções nas orações. O estudo morfológico organiza-se em 10 classes gramaticais: artigo, substantivo, adjetivo, pronome, verbo, advérbio, preposição, conjunção, numeral e interjeição.

💡 Observação Estratégica: Para provas e concursos, lembre-se de que a Morfologia analisa a palavra isoladamente (a sua classe gramatical), enquanto a Sintaxe analisa a função que a palavra desempenha dentro da frase. Algumas classes são flexíveis (variam em gênero, número, pessoa etc., como substantivo e verbo) e outras são invariáveis (não mudam de forma, como advérbio e preposição).

1. Artigo

Acompanha o substantivo para determiná-lo.

  • Artigos definidos = “a”, “as”, “o” e “os”.
  • Artigos indefinidos = “um”, “uns”, “uma" e “umas”.

2. Substantivo

Os substantivos são as palavras que dão nomes aos seres, coisas, estados, processos e sentimentos.

📌 Classificação dos Substantivos:

  • Comuns: indicam um nome comum a todos os seres da mesma espécie. Ex.: criança, árvore, cidade, estado, país...
  • Próprios: particularizam um ser. Ex.: Fernando, Vanessa, Ceará, Itália...
  • Concretos: seres reais ou imaginários que existem de forma independente de outros seres. Ex.: cadeira, Brasília, fada...
  • Abstratos: indicam seres dependentes de outros seres (ações, estados, qualidades e sentimentos). Ex.: feiura (é preciso alguém para ser feio), alegria (é preciso alguém para senti-la).
  • Coletivos: permanecendo no singular, representam muitos seres da mesma classe. Ex.: manada, boiada, discoteca...

📌 Formação dos Substantivos:

  • Primitivos: dão origem a outras palavras. Ex.: casa, mesa, mar, livro...
  • Derivados: palavra originada a partir da palavra primitiva. Ex.: casarão, mesinha, maresia, livreto...
  • Simples: formado de apenas um radical. Ex.: banana, plano...
  • Compostos: formado de dois ou mais radicais. Ex.: banana-maçã, planalto...

Plural dos Substantivos Compostos Separados por Hífen

1) Os dois elementos vão para o plural se a composição for:

  • Substantivo + substantivo: Couve-flor / couves-flores
  • Substantivo + adjetivo: Cachorro-quente / cachorros-quentes
  • Adjetivo + substantivo: Má-língua / más-línguas
  • Numeral + substantivo: Terça-feira / terças-feiras

2) Apenas o primeiro elemento vai para o plural se:

  • O segundo elemento limitar a ideia do primeiro: banana-maçã / bananas-maçã.
  • Os elementos forem ligados por preposição: pé-de-moleque / pés-de-moleque.

3) Apenas o segundo elemento vai para o plural se:

  • O primeiro elemento for verbo ou palavra invariável: Alto-falante / alto-falantes (advérbio + adjetivo).
  • Os elementos forem palavras repetidas: tico-tico / tico-ticos, reco-reco / reco-recos.

3. Adjetivo

É a palavra que caracteriza o substantivo. Eles podem indicar:

  • Qualidade: homem delicado
  • Estado: jogo tranquilo
  • Lugar de origem: mulher brasileira

📌 Formação dos Adjetivos:

  • Primitivos: aquele que não deriva de outra palavra. Ex.: pequeno escorpião / experiência amarga
  • Derivados: aquele que deriva de outra palavra. Ex.: menina amargurada (deriva de amargurar)
  • Simples: quando possuir apenas um radical. Ex.: olho escuro
  • Composto: quando possui dois ou mais radicais. Ex.: olho castanho-escuro

Plural dos Adjetivos Compostos

Geralmente se flexiona apenas o último elemento, porém temos duas exceções clássicas:

  • Azul-marinho e azul-celeste: não flexionam para o plural. Ex.: Terno azul-marinho / Ternos azul-marinho.
  • Surdo-mudo: nesta palavra, a flexão acontece com os dois elementos indo para o plural. Ex.: Meninos surdos-mudos.
Obs.: Adjetivos compostos referentes a cores, quando o segundo elemento é um substantivo, esse adjetivo será invariável (não terá flexão para o plural). Ex.: Camisas amarelo-ouro / Saias verde-abacate.

💡 Exemplos Extras para Fixação

Pés-de-galinha: Substantivo composto ligado por preposição. Apenas o primeiro elemento vai para o plural.
Pequeno-burguês: Adjetivo + Substantivo. Ambos os elementos flexionam: pequenos-burgueses.
Guarda-roupa: Verbo + Substantivo. Apenas o segundo varia: guarda-roupas.
Olhos castanho-claros: Adjetivo composto padrão. Varia apenas o último elemento.

📝 Exercícios Rápidos de Fixação

1. Indique a alternativa em que a palavra destacada é um substantivo abstrato:

  • a) O livro estava aberto sobre a mesa.
  • b) A saudade dos amigos aumentava a cada dia.
  • c) O estudante tirou nota máxima na prova.

2. Qual das opções apresenta o plural do substantivo composto grafado de forma CORRETA?

  • a) As couves-flores foram vendidas na feira.
  • b) Compramos dois pés-de-moleques deliciosos.
  • c) Os altos-falantes do evento estavam muito baixos.

3. Assinale a alternativa que traz um adjetivo derivado:

  • a) Olho azul.
  • b) Menino triste.
  • c) Atitude amargurada.

4. Na frase "Compramos trajes azul-marinho para a cerimônia", a expressão sublinhada permaneceu no singular porque:

  • a) É uma palavra invariável por ser verbo.
  • b)Trata-se de uma exceção dos adjetivos compostos que não flexiona no plural.
  • c) O primeiro elemento concorda com o substantivo.

5. O plural do adjetivo composto "surdo-mudo" é feito da seguinte maneira:

  • a) Surdo-mudos.
  • b) Surdos-mudo.
  • c) Surdos-mudos.
1. Resposta: B — Saudade é um substantivo abstrato, pois indica um sentimento que necessita de um ser para existencializar-se.
2. Resposta: A — Couves-flores flexiona os dois elementos (substantivo + substantivo). Em b) o correto seria pés-de-moleque e em c) alto-falantes.
3. Resposta: C — Amargurada deriva do verbo amargurar, sendo, portanto, um adjetivo derivado.
4. Resposta: B — As formas azul-marinho e azul-celeste são exceções invariáveis nos adjetivos compostos.
5. Resposta: C — O adjetivo composto surdo-mudo é uma exceção em que ambos os elementos flexionam para o plural.
